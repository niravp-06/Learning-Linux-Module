## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `locate <file>` | Locates file from saved cache database |
| `sudo updatedb` | Used to update database after a new file | 
| `history` | Prints previously typed commands in terminal |
| `history / grep "word"` | For finding specific commands by words |
| `<command> --help` | Fetches help page for that command  |
| `<command> man` | Opens full feldge manual for that command |
