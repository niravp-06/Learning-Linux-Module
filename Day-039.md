## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `cp <file> <location>` | Copying file from one location to another |
| `cp -r <directory> <location>` | Copying directory from one location to another | 
| `mv <file> <location>` | Moving file from one location to another |
| `mv -r <directory> <location>` | Moving directory from one location to another |
| `head -[no.] <file>` | Reading first n lines of a file |
| `tail -[no.] <file>` | Reading last n lines of a file |
| `sort <file>` | For sorting data of a file |
| `sort -r <file>` | Performing reverse sorting |
| `sort <file> / uniq` | Sorting data in unique format. i.e removes dublicate data |
