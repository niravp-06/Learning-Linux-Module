## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `shuf <file>` | Shuffles the content of the file |
| `wc <file>` | Prints word count with no. of lines, words, bytes, and file name | 
| `wc -l <file>` | Prints word count with only no. of  lines |
| `wc -m <file>` | Prints word count with only no. of words |
| `wc -c <file>` |Prints word count with only no. of bytes |
| `cmp <file A> <file B>` | Compares two files and show how they are same or not |
| `diff <file A> <file B>` | Fetches line by line difference of both files |
| `diff -u <file A> <file B>` | With -u for more readable data |
