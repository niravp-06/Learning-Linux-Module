## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `ls` | Lists files & directories names |
| `ls -l` | Lists files & directories, along with it's meta data info, including permissions, owner and timestamps |
| `ls -lh` | Displays the list info in human readable format. (eg: 4096 bytes --> 4k bytes) |
| `ls -lt` | Lists the data according to latest time order. New files/directory at top and old ones at bottom |
| `ls -ltr` | Lists in reverse time order. Old ones at top and new ones at bottom |
| `Cltr + L` | A keyboard shortcut for clearing terminal instantly |
