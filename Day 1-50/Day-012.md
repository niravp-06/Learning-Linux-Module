## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `ls -l` | Lists the permissions of file/directory |
| `chmod u=,g=,o= <file/directory>` | Change mode use to modify the permissions of file or directory |
| `chmod -R u=,g=,o= <directory>` | chmod used with recursive (-R) ensures that all changes also applies to all contents of directory |
