## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `cat <file name>` | For reading the contents for a file |
| `less <file name>` | For finding texts top to bottom or vice versa |
| `more <file name` | For reading file content page by page |
| `touch <file name>` | For creating a new empty file |
| `rm <file name>` | For deleting a file |
| `rm -r <directory name>` | For deleting a directory |
| `vi <file name>` | For creating and editing a new file |
| `nano <file name>` | For editing existing file in GNU nano editor |
