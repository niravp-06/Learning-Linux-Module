## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `split -l <no.> <file>` | Split files based on lines |
| `split -b <size> <file>` | Split files based on size | 
| `split -n <no.> <file>` | Split files based on fixed no. |
| `split -d -l <no.> ,<file>` | Split files with number ordering by using -d suffix |
| `grep "word" <file>` | Used to find desried words from a file |
| `egrep "word" <file>` | Used to find multiple desrired words from a file |
| `ls *<extension>` | * used to find files using letter or word |
| `ls <word>*` | Used to find files based on there extension |
| `touch hello{range}` | Creating files based on it's range at same time |
