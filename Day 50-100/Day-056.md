## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `apt` | Used for Debian/Ubuntu systems |
| `yum/dnf` | Used for Red-hat server systems | 
| `dpkg -l` | For listing low-level packages in Ubuntu  |
| `dpkg -l \ grep <package name>` | For lising specific low-level packages in Ubuntu |
| `apt list --installed` | For listing surface level packages in Ubuntu  |
| `snap list` | Lists the installed software/apps in the system |
| `apt search <package name>` | Lists the available versions of packages (Debian) | 
| `yum/dnf list available` | Lists the available versions of packages (Red-hat)|
