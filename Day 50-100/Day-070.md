## Topics Covered
- Process management
- Process status
- PID
- Killing a processs by name or PID

## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `systemctl status <name>` | Prints the process status of a process |
| `ps -ef` | Prints all the processes of the system |
| `ps -ef \ grep <name>` | Prints the specific process status|
| `pgrep <name>` | Provides the process ID (PID) of a process |
| `kill -9 <PID>` | Kills the process forcefully with PID |
| `pkill <name>` | Kills the process by it's name |
