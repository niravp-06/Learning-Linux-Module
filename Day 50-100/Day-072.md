## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `ifconfig` | Provides all network info |
| `ping <URL>` | Checks the internet and it's latency |
| `telnet IP Port` | Provides port info |
| `netstart -putan \ grep 80` | Checks port 80 (Web server) is open or not |
| `traceroute <URL>` | Traces all the routes to reach the URL |
| `reboot` | Reboots the server |
| `shutdown` | Shutdown the server |
