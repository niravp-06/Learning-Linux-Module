## Commands Practiced
| Command | What I Now Understand About It |
|---------|-------------------------------|
| `ssh <host name>` | Used to change to a different server/user |
| `scp file <host name> <location>` | Used for copying a file to remote location  |
| `chmod u=, g=, o= <file>` | Changes the permissions of the file |
| `chown <user name>  <file>` | Changes the owner of the file  |
| `chgrp <group name> <file>` | Changes the group of the file |
